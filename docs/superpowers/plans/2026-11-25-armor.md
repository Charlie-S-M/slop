# Armor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Forge, wear, compare, and sell armor (helmet, chestplate, boots) that blocks a share of
each hit.

**Architecture:**
- **Shared data:** `Armor`, `ArmorStats`, `ArmorBuilder`, and `Balance`.
- **Server:** `Forge` gets an armor branch; `Loadout` attaches worn pieces; `Arena` applies the
  block; `Economy` handles equip and sell.
- **Client:** the Forge target picker, cutscene armor support, and a Backpack Armor tab.

**Tech Stack:** Luau, Rojo, Jest specs run in Studio.

**Spec:** `docs/superpowers/specs/2026-11-25-armor-design.md`

## Global Constraints

- Every number lives in `Balance.luau`.
- Gun forging behaves exactly as before.
- Total block never exceeds `Balance.ARMOR_MAX_BLOCK` (0.75).
- Saves move to version 4, and old profiles get `armor = {}` and `equippedArmor = {}`.

## Review Focus

- A forged armor piece survives a crash mid-forge (`pendingForge` holds `armorId` and `slot`).
- Equipping a piece into the wrong slot, someone else's uid, or a garbage value does nothing.
- Selling an equipped or locked piece is refused.
- A full Eternal set at grade S still blocks at most 75%.
- Respawning re-attaches worn armor, and unequipping removes it from the character.

### Task 1: Catalog and stats

**Files:**
- Create `Shared/Armor.luau` and `Shared/ArmorStats.luau`.
- Add `ArmorItem` and `ArmorSlot` to `Types.luau`.
- Add the armor numbers to `Balance.luau`.
- Test: `Specs/Shared/Armor.spec.luau`.

**Interfaces produced:**
- `Armor.SLOTS = { "Helmet", "Chestplate", "Boots" }`, plus `Armor.get(id)`,
  `Armor.forSlot(slot, rarity): ArmorDef`, and `Armor.List`.
- `ArmorDef = { id, name, slot, rarity, set, body: Color3, trim: Color3 }`.
- `ArmorStats.roll(def, grade, roll): number`, which returns the defense.
- `ArmorStats.blocked(profile): number`, which sums the equipped pieces and caps the total.
- `Balance.armorSellPrice(item, rarity)`.

  - `forSlot("Chestplate", 5).id == "SunforgedChestplate"`.
  - Chestplate defense at rarity 5, grade B, roll 1 = 0.5 × 0.34.
  - A full Eternal S set at roll 1.1 is capped at 0.75 by `blocked`.
  - Unknown ids are ignored by `blocked`.

### Task 2: Saves and server forging

**Files:**
- `Types.luau`: `Profile.armor` and `Profile.equippedArmor`; `PendingForge.armorId?` and
  `PendingForge.slot?`.
- `PlayerData.luau`: version 4 and defaults.
- `Net.luau`: `ForgeArmor`.
- `Forge.luau`: pull ore validation into `takeOres`. Add `onForgeArmor`. In `finishProfile`,
  create an `ArmorItem` when `pending.armorId` is set.
- `ForgeStart`'s payload gains `armorId?`.
- `ForgeResult` sends `{ armor = ArmorItem, new }` for armor.

- [ ] Spec, using a pure helper if the server can't be driven from Jest: `ArmorStats.fromPending`
  builds the item from a pending forge plus accuracies.
- [ ] Playtest: forge a chestplate through the remotes, and confirm `profile.armor` holds it.
  Commit.

### Task 3: Blocking damage and wearing armor

**Files:**
- `Arena.damagePlayer`: scale by `1 - ArmorStats.blocked(profile)`.
- `Shared/ArmorBuilder.luau`: `build(def): Model`, made of studded bricks in the set colors, plus
  `attach(character, def)`.
- `Loadout.refreshArmor(player)`: called on spawn and on equip.
- `Economy`: remotes `EquipArmor(uid)`, `UnequipArmor(slot)`, `SellArmor(uid)`, and
  `LockArmor(uid)`, with validation and rate limits.

- [ ] Specs for the block in `Balance` or `ArmorStats`.
- [ ] Playtest: take a hit with and without a chestplate and compare the damage. Commit.

### Task 4: Forge UI and cutscene
